# 도착 모습 그림 프롬프트

페이지는 그림을 이 순서로 찾습니다. 파일이 없으면 다음으로 넘어가고, 다 없으면 지금 SVG가 나옵니다.

1. `img/race/종족명.png` (예: `img/race/와이번.png`) 종족별 그림이 있으면 우선
2. `img/egg.png` 같은 도착 형태 그림
3. 내장 SVG

형태 파일 이름은 egg, baby, seed, stone, drop, demonseed, bones, wisp, unknown 9개입니다. 정사각형, 배경 투명 PNG, 1024×1024 권장. 9장만 넣어도 전 종족이 커버됩니다.

## 공통 스타일 (모든 프롬프트 앞에 붙이기)

```
anime key visual style like "That Time I Got Reincarnated as a Slime", clean cel shading, soft rim light, warm fantasy palette, slight glow, single centered object, no text, no background, transparent background, 1:1
```

## 종족별로 더 만들 때

같은 공통 스타일 뒤에 "a newborn ___" 식으로 쓰면 됩니다. 파일명은 페이지의 종족 이름과 똑같이 써야 합니다.

인간, 엘프, 드워프, 고블린, 오크, 오거, 늑대, 트롤, 코볼트, 미노타우로스, 하피, 리자드맨, 와이번, 드래곤, 거미, 딱정벌레, 스켈레톤, 유령, 뱀파이어, 임프, 천사, 슬라임, 골렘, 트렌트

예: `img/race/드래곤.png` = a newborn golden dragon hatchling still half inside its egg, big eyes, tiny wings, soft glow
